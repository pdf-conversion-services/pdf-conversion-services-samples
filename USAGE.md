# Usage and quality guide

Use the screenshots to scope source format, output format, page count and layout priorities. The quality guide explains what to check against the source after conversion. These are project-planning examples, not completed conversion case studies.

## Conversion quality checklist

| Check | Acceptance question |
|---|---|
| Completeness | Are all source pages or records represented? |
| Text | Are characters, symbols, headings and reading order correct? |
| Tables | Are rows, columns, merged cells and numeric values accurate? |
| Layout | Are page breaks, margins, images and captions suitable for the target? |
| Editability | Can the intended content be edited in the target application? |
| Searchability | If OCR was requested, can representative text be searched and copied? |
| Handover | Do file names, formats and counts match the agreed brief? |

Check the converted output against the source at a representative sample size agreed for the project. Reconcile the full file/page inventory. The fields collect requirements; they do not execute conversion.
